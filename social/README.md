# Social-Media-Grafiken für actionabenteuer.de

Dieser Ordner enthält die fertigen Karussell-Grafiken für Instagram. Sie liegen hier,
weil das Planungswerkzeug (Buffer) Bilder nur über eine öffentliche Adresse abholen kann.

- `2026-12/` enthält die 13 Beiträge für Dezember 2026, je Beitrag ein Unterordner mit
  `feed-01.jpg` bis `feed-NN.jpg` (1080 × 1350 Pixel, in dieser Reihenfolge zu zeigen).
- Alle Grafiken sind selbst gezeichnet (Schrift Poppins, SIL Open Font License).
  Fremde Fotos sind nicht enthalten.

Die Dateien werden automatisch erzeugt. Änderungen von Hand gehen beim nächsten Lauf verloren.
